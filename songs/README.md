# Songs

- [Night Bus](night-bus/README.md): complete 134 BPM E-minor techno arrangement with eight controller tracks.
- [South African awakening](south-african-awakening/README.md): warm 122 BPM F#-minor deep house, extended chords, shuffled percussion and sparse vocal texture.
- [German Renaissance](german-renaissance/README.md): 140 BPM E-minor trance with rolling bass, supersaw arpeggios and a breakdown/build/drop arrangement.
- [Live set](live-set/README.md): build up a performance from a single kick.

For a new song, create `songs/<song-name>/song.js` and a README with tempo,
key, controller assignments, sample dependencies and how to start it. Use
`score.js` for a live-coding score that relies on the shared controller setup.
Use double quotes for Strudel mini-notation and single quotes for literal
MIDI device names and URLs. Keep a working version committed before experimenting.
