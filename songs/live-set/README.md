# Build a set live

Evaluate [the controller setup](../../controllers/launch-control-xl/setup.js)
once in your Strudel tab, then replace the editor with [score.js](score.js).
Only the kick is active initially. Uncomment or type one short musical part
at a time, keeping its `liveStrip` number attached to the same controller column.
Click Update while the groove continues.

Suggested progression: kick → hats/clap → bass → lead → vocal hook → breakdown
→ drop → gradual outro. Let major changes breathe for 8–16 bars. See the
[performance plan](../../docs/restart-and-perform.txt) for timing and recovery.

`liveStrip is not defined` means setup has not been evaluated in this tab.
Reloading the page clears it. The score has no automatic song arrangement.
